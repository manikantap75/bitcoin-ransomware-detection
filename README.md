# Bitcoin Transaction Ransomware Detection

A Machine Learning framework designed to analyze Bitcoin blockchain transactions and identify patterns associated with ransomware activities.

## 📌 Project Highlights
- Analyzed transaction graph networks to detect anomalies and identify ransomware-associated wallet addresses.
- Extracted behavioral features (address reuse, transaction velocity, loop behavior).
- Trained and evaluated classification models (Random Forest, XGBoost, Decision Trees).
- Implemented comprehensive exploratory data analysis (EDA) and performance evaluation (Precision, Recall, F1-Score).

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook
